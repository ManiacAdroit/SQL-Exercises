# SQL Exercises Challenge

Welcome to my SQL practice repository! This project tracks my journey through core database querying concepts, moving from foundational syntax to advanced data manipulation techniques. 

## 📂 Repository Structure

* **Exercise 1: SQL Fundamentals** – Standard SELECT statements, basic filtering (WHERE), and data sorting (ORDER BY).
* **Exercise 2: SQL Aggregates and Operators** – Data summarization using GROUP BY, HAVING, and aggregate functions (SUM, AVG, COUNT, MIN, MAX).
* **Exercise 3: Date Functions** – Extracting, formatting, and calculating intervals using temporal data types.
* **Exercise 4: Joins Exercise** – Combining tables using INNER, LEFT, RIGHT, and FULL OUTER joins to query relational schemas.
* **Exercise 5: Null Functions** – Handling missing data cleanly with COALESCE, IFNULL, and NVL operations.
* **Exercise 6: Union & Union All** – Stacking result sets and mastering set theory logic.

## 🛠️ Tech Stack & Focus
* **Dialect Focus:** Standard ANSI SQL / PostgreSQL / MySQL
* **Concepts Mastery:** Data Retrieval, Data Filtering, Relational Integrity, and Analytical Queries.
